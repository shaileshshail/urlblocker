    How patterns work
    • reddit.com blocks any URL containing “reddit.com”.
    • *youtube.com/shorts* blocks only YouTube Shorts. * matches anything.
    • /^https?:\/\/(www\.)?x\.com\// is a regular expression (wrap it in slashes, add i after the last slash to ignore case).
    • Matching is case-insensitive for wildcards and checks the whole URL, including the path and query.
    • Blocks apply immediately to every tab, including in-app navigation on sites like YouTube or Twitter.
